# Percussion Sample Library (`public/sounds/percussion/`)

Place your 6 genuine recorded percussion samples in this folder (`public/sounds/percussion/`) using the exact filenames below:

| Result P (`S % 7`) | Percussion Instrument | Required Filename |
|:---:|:---|:---|
| 0 or 6 | Bass drum / kick | `perc-bass-drum-kick.wav` |
| 1 | Snare drum | `perc-snare-drum.wav` |
| 2 | Hi-hat | `perc-hi-hat.wav` |
| 3 | Tambourine | `perc-tambourine.wav` |
| 4 | Woodblock | `perc-woodblock.wav` |
| 5 | Hand drum | `perc-hand-drum.wav` |

You can also record directly via microphone (`🎙 Record Mic`) or import `.wav`/`.mp3`/`.m4a` files per percussion instrument inside the browser UI!
